## Corrected findings

PR #12 contained two missed cases: initial sibling commits could replace the latest-rendered owner with an earlier instance, and releasing/reclaiming a suffixed id on rerender could overwrite another instance. The follow-up retains owned ids, leaves a newer rendered owner intact, and skips still-live ids when allocating after a disposal. Five regression tests cover the failures, suffix holes, StrictMode recovery and handover. Three fail on the pre-fix source; all pass fixed.

Independent verification: 960 tests passed, including 244 runtime tests and 120 Workbench UI tests. Build, typecheck, diff check, 11 package READMEs and eight public tarball dry-runs passed. One private Workbench native test still fails because installed Xcode profiles lack the geometry fields needed for its real-device bezel. It falls back to the generic frame. Do not describe the full recursive suite as green. No Workbench code was changed for this issue.
