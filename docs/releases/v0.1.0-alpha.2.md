# Runtime Inspector v0.1.0-alpha.2

Second public alpha, focused on React Compiler compatibility, animation discovery and component lifecycle fixes.

Thanks to Enzo Manuel Mangano (@enzomanuelmangano) for exercising Runtime Inspector in a real Expo app and contributing the React Compiler, discovery and lifecycle improvements.

## Changes

- Keep `// @inspect`, automatic animation discovery and scenes working with React Compiler (#7).
- Remove internal runtime import cycles exposed by Metro in the example app (#9).
- Preserve compilation for motion callbacks that read refs (#13).
- Discover JS-thread `sharedValue.set(withTiming/withSpring/withDelay(...))` writes and support Apply to code for them (#11).
- Remove component-scoped `// @inspect` controls on unmount (#12). Additional integration fixes keep controls attached to the right component during sibling mounts, rerenders, StrictMode and name collisions. Five regression tests cover those cases.

RIP stays at 0.3. There are no protocol schema changes. The SDK still ships CommonJS and retains helpers emitted by older Babel plugin versions.

## Upgrade together

Install matching versions of the SDK, Babel plugin and CLI:

```bash
npm install @runtime-inspector/react-native@0.1.0-alpha.2
npm install --save-dev @runtime-inspector/babel-plugin@0.1.0-alpha.2 @runtime-inspector/cli@0.1.0-alpha.2
```

New Babel output calls new SDK helpers, so upgrading only the plugin is unsupported. If using MCP or the DevTools panel, upgrade those packages to the same version. Clear Metro's cache after upgrading.

- GitHub CI and independent build, typecheck, package documentation and tarball checks pass.
- 960 original/integration regression tests pass. One unchanged private Workbench test fails because the installed Xcode iPhone profile omits geometry fields; its generic-frame fallback remains in use. The 120 Workbench UI tests pass separately. The full recursive test command is therefore not green.
- All eight packed public packages installed together into a fresh npm app outside the monorepo: Expo 58.0.16, React Native 0.88.0, React 19.3.0, Reanimated 4.7.1 and Worklets 0.13.0, with React Compiler enabled.
- iPhone 17 Simulator, iOS 27, Expo Go 58.0.7: initial sibling ownership, stable collision controls after a rerender, removing/reopening a collision row, per-row value changes, cleanup after unmount and replay of a motion callback reading a ref all verified through the broker against visible app text.
- `.set(...)` discovery creates duration/delay controls. Source write-back successfully changed the timing duration from 300 to 450 in App.tsx. The app refreshed successfully.
- React Compiler reports the same four successful component compilations with and without instrumentation for the smoke fixture.
- A production iOS export succeeds. A production transform of the smoke app contains no injected inspector helpers.

Final alpha.2 archives were installed together and their dependency tree contains only alpha.2 Runtime Inspector packages. Archive metadata and internal dependency ranges are correct, and all built files are byte-identical to the candidate exercised on the Simulator. The final alpha.2 broker and app were restarted for a final smoke check.

## Limits

This release was validated on the iOS Simulator. Android, physical devices, bare React Native and pnpm/yarn consumer paths have not been newly validated.

Duration-based spring tuning and animations returned by `useDerivedValue` remain draft RFCs (#10), not shipped features. Worklet/gesture-thread discovery is excluded. Shell Studio is paused and excluded. The desktop Workbench stays private and is not an npm release artifact.

The alpha remains intended for local development on a trusted network.
